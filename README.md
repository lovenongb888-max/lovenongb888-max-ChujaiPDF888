# PDF888

แอป Expo/React Native สำหรับแปลง PDF เป็นภาพบนอุปกรณ์ โดยมีหน้าจอไทย/อังกฤษ เลือก PNG/JPG หรือ Image (บันทึกเป็น PNG), เลือกความละเอียด, ดูตัวอย่าง, บันทึกรูปในคลังภาพ และส่งภาพที่เลือกผ่าน Android share sheet ไปยังแอป Cloud drive ที่ติดตั้งไว้. สำหรับ PDF ที่มีรหัสผ่าน จะขอรหัสผ่านผ่าน popup และมีปุ่มเลือกแสดง/ซ่อนข้อความที่กรอก โดยไม่บันทึกรหัสผ่านไว้ในแอป.

## ความเป็นส่วนตัวและขีดจำกัดอุปกรณ์
PDF และรูปที่แปลงเก็บไว้ชั่วคราวใน cache ของเครื่องระหว่างทำงานและลบเมื่อล้างรายการ/ยืนยันออกจากแอป ไม่มี backend upload หรือการจัดเก็บ PDF ใน server. PDF.js renderer โหลดจาก CDN; เนื้อหา PDF ไม่ถูกส่งไปยัง CDN. ไม่มีเพดานขนาดไฟล์/จำนวนหน้าในโค้ด แต่การอ่านไฟล์และแปลงภาพต้องใช้หน่วยความจำและพื้นที่จัดเก็บของเครื่อง จึงไม่สามารถรับประกันไฟล์ขนาดไม่จำกัดบนอุปกรณ์จริงได้. แอปทำงานทีละหน้า.

## ตรวจสอบรุ่นใหม่
หากต้องการเปิดใช้การแจ้งเตือนรุ่นใหม่ ให้ตั้ง `EXPO_PUBLIC_UPDATE_MANIFEST_URL` ตอน build ให้ชี้ไปยัง JSON เช่น:

```json
{"version":"1.1.0","apkUrl":"https://example.com/PDF888-1.1.0.apk","releaseNotes":"Bug fixes"}
```

APK ที่ติดตั้งทับรุ่นเดิมได้ต้องใช้ Android application ID เดิมและ signing key เดิม. โค้ดตรวจสอบรุ่นและเปิดลิงก์ดาวน์โหลด; Android installer เป็นผู้ทำการแทนที่หลังผู้ใช้ยืนยัน.

## พัฒนาและส่งออก

```sh
pnpm install
pnpm check
pnpm dev
```

Android release artifact สร้างผ่าน Dashboard > Build > Android APK หลังโปรเจกต์มี checkpoint ที่ยอมรับแล้ว; ไม่สร้าง/อ้างว่า APK สำเร็จจาก Expo Web preview. การบันทึกลงอุปกรณ์ต้องอนุญาต photo/media access. การส่งไป Cloud drive ใช้ share sheet ของระบบและแอปปลายทางที่ผู้ใช้ติดตั้ง.
